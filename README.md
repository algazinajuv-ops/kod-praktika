# КодПрактика

Тренажёр для Python и JavaScript. Выбери один из трёх уровней, прочитай условие и напиши решение. **Запустить** выполняет код на твоём вводе, **Проверить** прогоняет все тесты. Во вкладке **Проверка знаний** доступны три вопроса с объяснениями по теме задачи.

## Запуск с нуля

Установи Node.js 24 или новее. В PowerShell выполни команды:

```powershell
git clone https://github.com/algazinajuv-ops/kod-praktika.git
cd kod-praktika
npm start
```

Открой `http://127.0.0.1:8790/`. Устанавливать пакеты npm не нужно. Учебные примеры работают без ключа. Для первого запуска Python браузер загружает Pyodide с CDN. JavaScript выполняется в браузере без загрузки дополнительной среды.

## Генерация задач

**Локальная Ollama.** В терминале проверь, что служба Ollama запущена и `ollama list` показывает загруженную локальную модель. Перед стартом приложения укажи её точное имя:

```powershell
$env:OLLAMA_MODEL = 'имя-модели-из-ollama-list'
npm start
```

Сайт сам выберет Ollama, если серверный ключ OpenAI не задан. При использовании Ollama запрос на генерацию идёт на `127.0.0.1:11434`.

**OpenAI.** Войди в **Настройки ИИ** и введи свой ключ OpenAI API. Он хранится в памяти вкладки до обновления. Владелец закрытого хостинга также может задать секрет `OPENAI_API_KEY`. Модель можно поменять через `OPENAI_MODEL`. У запросов к OpenAI может быть стоимость.

ИИ составляет условие, тесты, эталон и вопросы. Перед показом задачи браузер запускает эталон на каждом тесте. Это выявляет расхождения с ожидаемыми ответами. Формулировки и объяснения модели могут содержать ошибки.

## Как устроен проект

- `index.html` и `styles.css` задают интерфейс и адаптацию под телефон.
- `app.js` обновляет интерфейс, сравнивает результаты и проверяет ответы на вопросы. `data.js` содержит стартовые упражнения.
- `runner.js` выполняет учебный код в отдельном Web Worker с лимитом времени и вывода. Проверка рассчитана на самостоятельную практику.
- `server.mjs` запрашивает задачу у выбранной модели. Ученический код на сервер не отправляется.

`npm run build` собирает `dist/server/index.js` для Cloudflare Workers. Для доступа с телефона можно использовать HTTPS-развёртывание с OpenAI. Локальная Ollama доступна в режиме `npm start` на том же компьютере.
